## Как запустить
- **Новая сессия Claude Code в этом репо** (`cd` в проект → новый чат) — есть MCP-tools,
  playwright и доступ к файлам на чтение/запись (сможет вести реестр и отчёты).
- Для разведки нужен залогиненный `recon_adlib_profile` (FB-расходник); для генерации —
  `recon_profile` (syntx). Первый вход — `--headed --login` (см. README, быстрые команды).
- Claude Desktop — MCP-tools работают, но запись файлов/скрипты требуют filesystem-MCP.
