## §0. Интейк: как байер передаёт пул агенту

Папка: `~/Documents/FB_Agent_Creo/_intake/<GEO>_<SLOT>/` (напр. `GH_CR2/`). Байер кидает туда:
- **медиа** — статика + видео (имена файлов любые);
- **тексты** — `texts.md`: собранные `primary_text`/`on_image` с найденных креативов (с пометкой,
  с какого креатива/фанки) + по желанию выгрузка текстов из Ads Manager;
- **`notes.md`** (опц.) — фанка, сколько живёт ПО ФАНКЕ (не по датам Tyver), гео, где найдено.

Агент на интейке:
1. Инвентаризация: список файлов, формат (static/video/ugc_text), дубли.
2. **Каждый файл — через extraction-протокол §1** (визуально СМОТРИМ картинку/кадры, ЧИТАЕМ текст);
   собранные тексты (`texts.md` / Ads Manager) разбираем тем же §1 (текстовый слой) — это и есть
   «анализируем тексты вместе», см. §3.
3. Уточняющие вопросы байеру — одним батчем (живучесть по фанке, гео-привязка, что зацепило).
4. Выход: `references` в `geo/<GEO>/slots/<SLOT>.yaml` + хуки-кандидаты в `hooks.yaml`
   (`verdict: testing`, вкл. text-хуки) + отчёт разведки `geo/<GEO>/reports/<SLOT>_<DATE>.md` (R9).

## §1. Выявление хуков и подходов (extraction)

### Принципы анализа
- **Копируем РАБОТАЮЩЕЕ, не ищем «свободные слоты».** Сигнал «работает» = живучесть по фанке ×
  скейл (N копий) × свежесть — В СОВОКУПНОСТИ. «Никто так не делает» = red flag (тестировали — сдохло).
- **Образец — скейлеры нашего типа** (performance-affiliate). Бренды (Betway/Betano/1xBet)
  механически не копируем — у них узнаваемость и бюджет, у нас прямой отклик.
- **Связка неделима:** формат × хук × сумма × эмоция × язык. Копировать связку, не отдельный приём.
- Знание без цифр — мнение: всё извлечённое получает `verdict: testing` до наших FTD.

### Extraction-промпт (шаблон для агента; прогонять на КАЖДЫЙ креатив пула)

```
Разбери рекламный креатив (gambling, FB) как media-buyer. Дай структурированный разбор:

1. ФОРМАТ И ПОДАЧА
   - Тип кадра: нативный FB-пост / чат-скрин (WhatsApp/SMS) / скрин геймплея /
     before-after / фото человека / direct-баннер / видео (что в первых 3 сек?)
   - Глянец или «народное» (UGC)? Чем достигается достоверность (нативный UI, бытовой
     фон, несовершенство фото)?

2. ХУК — что цепляет в первую секунду (ranked, до 3):
   - психология: жадность / FOMO / доверие-к-выплате / низкий-порог / адреналин /
     социальное-доказательство / любопытство
   - чем выражен: сумма? пруф зачисления? лицо-эмоция? вопрос? интрига?

3. ТЕКСТ (два слоя, дословно):
   - on_image: все надписи на картинке + ГДЕ расположены (плашка/кнопка/чат/заголовок)
   - primary_text: хук-первая-строка, структура (сторителлинг/директ/вопрос), язык и
     вставки (Pidgin/Twi/суахили), числа и валюта, эмодзи, CTA
   - полнота: none / partial / full

4. TRUST-ПРИЁМЫ: платёжный якорь (MoMo/M-Pesa пуш, SMS), «официальность» (рег.номер,
   1M players, рейтинг), комменты-соцпруф, знакомый UI, селебрити/футбол

5. ВОРОНКА: куда ведёт (Google Play прокладка / PWA / директ-ленд), CTA-кнопка FB

6. ПОЧЕМУ ЭТО РАБОТАЕТ (гипотеза одним абзацем): какую боль/желание давит, почему
   аудитория гео верит, что делает связку цельной

7. ЧТО ПЕРЕНОСИМ СЕБЕ:
   - формула связки одной строкой (формат × хук × сумма × эмоция × язык)
   - адаптация под наш оффер/гео: что МЕНЯЕМ (кошелёк, валюта+суммы из production_profile,
     имена, игра под наш welcome-bonus), что СОХРАНЯЕМ (структуру, психологию, расположение)
   - риск копии: что выжжено (если видел N клонов — вариация обязательна)

ВЫХОД дополнительно в YAML под _schema.md: reference{id, source, advertiser, format,
why, long_active_days?} + hooks-кандидаты{id, level, type, text, verdict: testing}
+ idea{id, desc, type, hooks[]}.
```

### Пост-обработка пула (после разбора всех файлов)
- **Кластеризация**: сгруппировать по хук-типам → таблица «подход × сколько конкурентов × макс
  живучесть × скейл». Подход с 3+ независимыми конкурентами = валидированный рынком.
- **Карта сумм**: какие суммы/валюты в ходу у скейлеров (наш диапазон — от них, не выдумывать).
- **Приоритизация батча**: чемпион (наш) + челленджеры из топ-кластеров. Размер = функция находок.
- Инструменты-помощники: `analyze_creative` (hook/pain/CTA/proof), скилл
  `competitive-ads-extractor` (слой анализа), `score_gambling` (отсев мусора).

## §2. Генерация от референса (generation)

### Пайплайн (референс → промпт)
1. **Декомпозиция референса** — берём из extraction §1: формула связки + «что сохраняем».
2. **Маппинг на наш оффер/гео** (по реестру, не из головы):
   - суммы/валюта → диапазон гео из QA-чеклиста (`creative-gen.md`; GH: GHS 1,500–6,000, некруглые);
   - кошелёк → главный оператор `market_profile.payment_operators` (GH: MTN MoMo);
   - язык → **как у скейлеров рынка** (урок GH_AVI 2026-06: English; Pidgin максимум 1 фраза-специя);
   - имена/типаж/фон → `production_profile.typage` (локальные, бытовое окружение);
   - телефон в кадре → Android-статусбар (Tier-3), НЕ iPhone;
   - игра/бонус → под наш welcome-bonus (`offer-profiling.md`).
3. **Сборка промпта** по структуре ниже (+ шаблон типа кадра).
4. **Генерация 2–3 вариантов**, менять ОДНУ переменную между ними.
5. **QA-гейт** — чеклист в `creative-gen.md` (анатомия/текст/чат-порядок/суммы-синхрон/UI). Брак → REJECT.
6. **Реестр**: `creative{code, visual_hooks, text_hook, angle, inspired_by: <ref_id>, status: ready}`.
   `code` = `sub3`, `angle` = `sub6` — петля на FTD замкнётся автоматически.

### Структура генерационного промпта (блоками, от общего к частному)
GPT Image 2 — reasoning-first: ясное связное описание > «магические хаки».
```
[1 ТИП КАДРА]    authentic Facebook post screenshot / WhatsApp chat screenshot /
                 phone gameplay screenshot, NOT a glossy ad
[2 СУБЪЕКТ+СЦЕНА] кто/что в кадре, действие, бытовой фон гео (street kiosk in Accra...)
[3 КАМЕРА/РЕАЛИЗМ] shot on phone, natural light, candid, slight imperfections, off-center
[4 ТОЧНЫЙ ТЕКСТ]  каждая строка В КАВЫЧКАХ + МЕСТО: render exactly "..." inside the
                 green notification bar; caption above the photo: "..."
[5 ИНВАРИАНТЫ/ЗАПРЕТЫ] no gibberish, correctly spelled; chat input field EMPTY;
                 Android status bar; no watermarks; hands natural with five fingers
```
**НЕ писать** `ultra realistic / 8k / masterpiece` — делает картинку искусственнее.
Негативов умеренно (2–4), не простыня.

### Шаблоны по типу кадра (правила правдоподобия)
- **Нативный FB-пост** (формула чемпиона CR005): пост на весь кадр + крупный зелёный
  пруф-пуш зачисления (системный UI, НЕ дизайн-плашка) + скепсис-преодоление в тексте +
  2–3 живых коммента. Суммы: пуш = headline = одна цифра ВЕЗДЕ.
- **Чат-скрин** (WhatsApp): порядок строго СВЕРХУ-ВНИЗ по времени — триггер (forward
  MoMo-пруфа) ВЫШЕ и РАНЬШЕ, реакции НИЖЕ и ПОЗЖЕ (фиксировать таймстампы в промпте:
  `MoMo forward at 17:40 FIRST, replies at 17:41-17:42 BELOW`). Заголовок без артефактов
  («All chats», не «All cats»). Поле ввода ПУСТОЕ, CTA — отдельным баннером.
- **Скрин геймплея**: UI НАПОЛНЕН (множитель + Cash Out + сумма), не пустой шаблон;
  сумма Cash Out = сумме пруфа.
- **Before/After**: обе панели читаемы, суммы контрастны (0.27 → 64.80), один кошелёк.
- **Фото человека**: одна рука в действии, вторая вне кадра; эмоция конкретная
  (skeptical → relieved); мелкое лицо не детализировать.

### Анатомия (частый брак)
Позитивные якоря: `hands natural with five fingers, relaxed pose, correct proportions`.
Упрощай позу; ломается — кадрируй руку вне кадра.

### Инварианты при перегенерации
Меняй ОДНУ вещь за раз, остальное фиксируй явно: `keep same layout, profile photo and
colours; only fix the badge text`. Между батчами/концептами — НОВЫЙ чат (контекст тащит
стиль → штамп). Лимит итераций 2–3 → флаг байеру.

### Серия (батч целиком)
N креативов = N РАЗНЫХ сигналов (хук/формат/сумма/персонаж), не одна реклама ×N. Смотреть
серию в совокупности: единообразие стиля гео — да, штамп — нет.

## §3. Тексты (primary_text / headline) — анализ существующих, НЕ генерация с нуля
Флоу 2026-06-09: **тексты не сочиняем с чистого листа — берём работающие и адаптируем.**
Два источника:
1. **Анализ Ads Manager** — какие тексты реально используются/крутятся (на наших кампаниях,
   разрез по `sub6`-углам). Что уже льётся = проверенная фактура.
2. **Сбор с референсов** — байер собирает `primary_text`/`on_image`-текст с найденных креативов
   (вручную, при сборе пула) → скидывает агенту → **совместный анализ** (extraction §1, текстовый
   слой) → отбираем рабочие формулировки → адаптируем под наш оффер.

Адаптация под оффер/гео (не дословная копия): суммы/валюта из диапазона гео, кошелёк
(`market_profile`), язык как у скейлеров рынка (GH: English; Pidgin — 1 фраза-специя), наш
welcome-bonus. Структуру хука/тон/последовательность — сохраняем (это и есть «что работает»).

> Текстовый интейк: байер кладёт собранные тексты в `_intake/<GEO>_<SLOT>/texts.md` (или прямо
> в `notes.md`), помечая, с какого креатива/фанки. Агент разбирает их вместе с визуалом.

### Свобода формулировок (gambling-freedom)
Прямое соглашение с Meta (см. `creative-gen.md`): дисклеймеры не нужны, жёсткие хуки
(деньги/выигрыш/вывод/бонус) разрешены, самоцензуры нет. Старый guardrail «запретные слова»
(`guaranteed/free money/hack/cheat`) **снят** решением байера. При переносе чужих рабочих
формулировок не смягчаем их «на всякий случай».

> Автогенерация текстов внешними LLM (DeepSeek/GLM) — это roadmap авто-сервиса креативной
> аналитики (`creative-analytics.md`), НЕ текущий ручной флоу. Сейчас тексты = анализ + перенос.
