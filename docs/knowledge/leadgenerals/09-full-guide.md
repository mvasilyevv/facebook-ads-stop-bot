# Полный запуск с нуля: методология и трекинг

Ролик «Гемблинг арбитраж с нуля: полный запуск для новичков — фулл гайд 2026»,
80 мин, 13.04.2026. Источник: `2RPxZP_iv7c`. Гео примера — Турция.

Самый систематический ролик серии: методология излагается подряд, а не
вплетается в кейс. Зато **стоп-правил в нём почти нет** — автор явно откладывает
ведение и масштабирование на следующий ролик [01:18:51].

16. Ведение и масштабирование — **вынесено в следующий ролик**

Про CTR важна формулировка целиком: «CTR не меньше полтора держится... **И мы

нельзя.

## Явное предупреждение против жёстких порогов

> «KPI однозначно со временем будет меняться и от гео к гео тоже... будьте
> максимально пластичными, не будьте шаблонными, больше тестируйте» [01:12:42]

Прямое основание держать все пороги настраиваемыми, а не константами. Совпадает
с выводом из [06-za-second-pass.md](06-za-second-pass.md), где цифры той же
команды разошлись между роликами.

## Структура и настройки

- **CBO** [00:59:10]
- **Ручная ставка «цена за результат»** (cost cap), названа лайфхаком автора
  [00:59:30]. Механика масштабирования: «вы можете сюда поставить хоть бюджет
  двадцать тысяч, он у вас не будет скручивать ту сумму... Он будет искать те
  результаты, которые вы выставляете по стоимости выкупа депозита» [00:59:57]
- **Структура 1-3-1**, нотация: кампании — адсеты — объявления [00:57:55]
- **Таргетинг максимально широкий**, без сужения по возрасту, полу, языку,
  плейсментам [01:03:18]
- **Отложенный запуск с нулей по таймзоне кабинета** [01:01:56]
- **Все три текстовых поля** объявления: headline, description, primary [01:04:14]
- **Формат**: Flexible и карусель [01:04:26]
- **Кабинеты с разными таймзонами** как элемент диверсификации [01:06:28]

Какое именно событие выбрано целью оптимизации адсета, в сцене создания
кампании **не проговаривается** — только «цель по цене за результат» и сумма $60
при ставке $75. По косвенным признакам это депозит, но прямой цитаты нет.

## Трекинг

- Три события пикселя: **Lead** (= установка PWA либо клик по кнопке на ленде,
  активен по умолчанию), **Purchase**, **Complete Registration** [00:20:50]
- Частая ошибка: «Обязательно выберите потом второе событие, а то многие,
  настроив завершённую регистрацию, нажимают "Далее"» [00:22:02]
- Параметры информации о клиенте заполняются **для каждого события отдельно**
  [00:22:18]
- Цепочка постбэков: трекер рекламодателя → трекер партнёрской сети → AdSet Pro
  → Ads Manager [00:13:08]
- **Чистота ссылки** — без пробелов, процентов, запятых, иначе «редирект не будет
  отрабатывать и могут теряться постбэки». Повторено дважды [00:17:07], [01:05:18]
- Один пиксель используется долгосрочно ради накопления данных под lookalike
  [00:34:04]

Это уточняет наше D-9: событий на пикселе **три**, а не два, и установка PWA
маппится именно в Lead.

- Турция на старте — только слоты, без краш-игр [00:27:22]. Оговорка: краш даёт

- Видео обязательно с кастомной уникализированной обложкой [01:09:24]

- Сокрытие от спай-сервисов конкурентов: белый креатив в миниатюре Flexible или
  карусели, гембловый показывается целевому пользователю [01:10:20]

## Чего в ролике нет

Стоп-правил вида «потрачено X, результата нет — стоп» **не сформулировано ни
одного**. Есть только качественное про кабинеты: «один кабинет стрельнет,
зацепится, другой будет систематично давать негативный результат. Не стоит в
него уверовать, не стоит уходить в тильт... не стоит на нём сливать деньги»
[01:06:43] — без суммы, срока и числа попыток.

Для правил авто-стопа этот ролик материала не даёт.
