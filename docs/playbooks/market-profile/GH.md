## Рынок (market_profile)
- **Язык:** English + **Pidgin/Twi** (Chale, Ɛyɛ, sharp sharp, no wahala). Конкуренты пишут чистым English → **Pidgin/Twi = наш дифференциатор**.
- **Деньги:** **MTN MoMo доминант** (+ Telecel Cash). Главный кошелёк = ядро payment-trust хука.
- **Идентичность:** **футбол** (GPL, ЧМ-2026), 🇬🇭, kente.
- **Девайс:** Android, Tier-3.

## Производственный профиль (production_profile)
- **Стиль:** Tier-3 **народно, НЕ глянец** (глянец читается как реклама → хуже конвертит на холодную).
- **Формат:** статика-старт (отлаженный пайплайн); видео массовее у конкурентов → видео-тест после первых FTD.
- **Штамп рынка (отстройка):** красный самолёт на тёмном/огненном фоне + золото. Наш ключевой креатив **ЛОМАЕТ штамп**: реальный скрин/пост, MoMo-плашка фокусом, без глянцевого самолёта-оверлея.

## Конкуренты (Aviator, на 2026-05-31)
- **Бренды** (глянец, direct-воронка): Betway (free-flights + MoMo + GPL + cashout, «GHS 1M»), Betano (match-бонус «GHS 2000»).
- **Серые** (видео / app-прокладка): Luck&strategy (скейл ×20, FOMO/greed/«millionaires»), Bang-0911 (low-entry «GHS 10»), Ghmjngh (adrenaline + MoMo-пруф + kente), Crazy Spinners («20 bonus flights»).
- **Шум** (отсев): aviator-predictor scam, SPRIBE B2B, aviator-очки.

## Что рынок УЖЕ занял (НЕ дифференциаторы)
MoMo-пруф (Ghmjngh), bonus-flights (Crazy Spinners), локальный типаж / 🇬🇭 / kente, греда / FOMO.

## Что РЕАЛЬНО свободно (наши дифференциаторы)
1. **Полная нативность** — реальный пост/скрин (MoMo SMS / геймплей / отзыв в ленте), НЕ дизайн-баннер. Этого нет ни у кого (CR005 победил на KE именно этим).
2. **Pidgin/Twi** в тексте.
3. **Правдоподобная сумма** под low-entry 10 GHS (у всех фейковые 24,700/1M → ниже доверие на холодную).
4. **Прямой залив без app-прокладки** (наш whitelist убирает лишний шаг конкурентов).
