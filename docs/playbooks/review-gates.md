# Playbook: Ревью-гейты (qa)

> Источник правды агента `qa`. Читать ПЕРЕД ревью. Правки — только с апрува байера.
> Роль в команде, формат вердикта, лимит итераций — `team-protocol.md`.

## Статус
- ✅ **работает:** методология гейтов; чеклист креативов обкатан (уроки GH_AVI: инвертированный чат, дубль уведомлений, чужой оффер).
- ⚠️ **грабли:** генератор пропускает брак «замыленным глазом» — qa обязан смотреть артефакты ГЛАЗАМИ (Read картинок) и скриптами, а не верить пересказу воркера.

## Принципы
1. **qa НЕ исполнитель.** Ничего не генерит/не строит/не заливает/не правит. Только смотрит и выносит вердикт.
2. **Первоисточник, не пересказ.** Картинки открывать (Read), кампании читать verify-скриптами (read-only), ссылки открывать.
3. **Вердикт = ✅ APPROVE / ❌ REJECT + пронумерованные пункты** (что и где исправить, со ссылкой на пункт чеклиста/playbook). «Не нравится» без пункта — не вердикт.
4. **Цифры > мнения.** Вкусовщину не навязывать. REJECT — только за нарушение чеклиста/playbook/внутренней логики артефакта (абсурд, рассинхрон, чужой бренд).
5. 3 итерации REJECT на гейте → эскалация lead'у (дальше решает байер).
6. Новый пойманный паттерн брака → ПРЕДЛОЖИ diff в чеклист соответствующего playbook (сам не правь).

## Gate A — креативы (от `syntx`)
**Вход:** папка генератов + использованные промты + референс + offer-код.
По КАЖДОЙ картинке — **QA-чеклист из `creative-gen.md`** (анатомия/реализм · текст/gibberish · логика чат-скринов сверху-вниз · наполненность UI игры · суммы в диапазоне гео и синхрон MoMo=CashOut=headline · брендинг · язык гео · серия в совокупности). Дополнительно:
- **оффер наш**, не чужой (бонус/механика = `offer-profiling.md` + вводные байера; урок «+100%/промокод»);
- при «визуал × N текстов» — синхрон сумм картинка↔текст (или тексты сумма-агностик);
- серия = N разных сигналов, не один штамп ×N;
- референс реально использован (reference-based, не text-to-image).

**Выход:** вердикт по каждому креативу + общий по серии → `syntx` (и статус в тасклист).

## Gate AV — видео (от `video`)
**Вход:** папка mp4 + **раскадровки** (ffmpeg) + промты/модель + статик-источник (для I2V) + референсы (Library ID).
mp4 напрямую не смотрится — qa смотрит РАСКАДРОВКУ каждого ролика (Read кадров) + постер. Нет раскадровки → REJECT сразу (вернуть за кадрами). По **QA-чеклисту видео из `video-gen.md`**:
- хук 0-3с (крупная цифра/эмоция в первых кадрах) · звуконезависимость (смысл без аудио);
- 9:16, длина по паттерну · драматургия (рост → краш/кэшаут → реакция), ключевой момент не позже середины;
- суммы правдоподобны + **синхрон экран↔оверлей↔текст** + валюта гео · UI игры наполнен (чеклист статики применим к кадрам);
- оверлеи без gibberish, CTA-момент есть · люди: без морфинга рук/лиц между кадрами;
- брендинг: без чужих лого и вотермарок генераторов · I2V: первый кадр = Gate-A-статик;
- серия = N разных сигналов · соответствие офферу/бонусу (`offer-profiling.md`).

**Выход:** вердикт по каждому ролику + серии → `video`; ✅ → `video` уникализирует аппрувнутые (`scripts/uniquify_video.py`, копии qa повторно НЕ смотрит — md5-вариация оригинала) → папка `fb`.

## Gate B — PWA + трекер (от `adsetpro`)
По `pwa-tracker.md`:
- **PWA evergreen:** БЕЗ бонуса/сумм в листинге/описании/отзывах; название = игра, разработчик = провайдер; рейтинг/отзывы правдоподобны (не раздуты);
- **отзывы локальные** под гео (`market-profile/<GEO>.md`): имена, MoMo-вывод, вкрапления Pidgin/Twi;
- **ассеты = Gate-A-аппрувнутые** (та же серия, единый стиль, форматы ICON/FEATURE/SCREEN);
- **трекер:** потоки разбиты по OS (Android/iOS/Other), оффер в КАЖДОМ потоке, сплит-тест PWA/офферов в Rotation (веса выровнены), без битых связок, гео-фильтр + антибот-фильтры + пиксели на месте;
- **трекинг-ссылка:** открывается, ведёт на наш PWA, sub-макросы (sub3/sub6) прокидываются.

**Выход:** вердикт + подтверждённая ссылка → `adsetpro` (далее она уходит `fb`).

## Gate C — кампания (от `fb`, PAUSED, ДО байера)
По выводу `verify_campaign.py <id>` + разделу «Стандартные правила» `campaign-launch.md`:
- objective **OUTCOME_SALES** + `promoted_object` (pixel_id, PURCHASE, `smart_pse_enabled:false`) — не TRAFFIC;
- **start_time** = следующие сутки 00:00 в TZ кабинета; дата в имени = today+1; act_id = подтверждённый байером;
- **страница** = выбранная байером; **нейминг** = согласованный формат;
- гео = `[<ISO>, AQ]` (Антарктида всегда); ABO: `bid_strategy` на адсете, кампания БЕЗ бюджета;
- `text_optimizations` = OPT_OUT (если байер не сказал иначе);
- **url_tags:** sub2=MV · sub3=код креатива · sub4=числовой id БЕЗ `act_` · sub6/sub7 = имена Meta · sub8=`{{ad.id}}` для точной live-атрибуции;
- структура = методология этапа (этап 1: N адсетов × 1 ad, ЕДИНЫЙ текст; не 5×3);
- все объекты **PAUSED**; нет дублей/осиротевших (`check_campaigns.py`);
- креативы в ads = аппрувнутые на Gate A (статика, image_hash) / Gate AV (видео, video_id+thumbnail), destination = Gate-B-ссылка.

**Выход:** вердикт → `fb`; ✅ → lead отдаёт байеру (ревью в Ads Manager → байер сам unpause).
