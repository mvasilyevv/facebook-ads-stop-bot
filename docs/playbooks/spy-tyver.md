# Playbook: Поиск креативов (Tyver + Ad Library)

> Как искать чужие рабочие FB-креативы под gambling — основной операционный навык байера.
> Зафиксировано на менторском разборе заливов 2026-06-09 (наставник показывал поиск в Tyver
> вживую). В дополнение к методологии разведки `SOP.md §R1–R7`. Правки — только с апрува байера.

## Статус ✅ работает (ручная разведка через браузер).

## Зачем и сколько
Цель — набрать **пул креативов-челленджеров** под гео/слот. На один залив берём **10+ креативов
(минимум 10)**, по всем вариациям слота (напр. Chicken Road 1 И Chicken Road 2). Выкачиваем
**всё** — и статику, и видео. Найденное — не копируем 1:1, а дорабатываем под нашу формулу
(`SOP.md §R5`, `creative-gen.md`); генерация — GPT Image / иногда руками.

## Источники (комбинировать, не один)
1. **Tyver** (`app.tyver.io`) — основной spy-сервис, поиск по фильтрам (ниже).
2. **Facebook Ad Library** — добор по фанпейджам конкурентов (ключевой workflow, см. ниже).
3. **MCP-агент** — параллельный автоматический анализ (наставник: «не только в Tyver смотрю,
   ещё запускаю анализ агента через MCP-перехват»). Tyver — не единственный канал.

## Разделение труда: сбор — байер, анализ — агент (2026-06-09)
**Сбор креативов остаётся на человеке (байере).** Ручной сбор требует того, что плохо
автоматизируется: смотреть фанку, ставить мобильные прокси нужного гео, заходить с телефона,
обходить фильтры доступа, «прыгать по фанкам» вглубь. **Задача агента — анализ собранного**:
hook / pain / CTA / proof, паттерны, мета-сигналы живучести, отбор челленджеров под нашу
формулу, занесение в реестр (`SOP.md §R3–R7`, tool `analyze_creative`). То есть байер приносит
пул, агент его разбирает и приоритизирует — не наоборот.

**Как передать пул агенту:** скинуть файлы в `~/Documents/FB_Agent_Creo/_intake/<GEO>_<SLOT>/`
(+ опционально `notes.md`: фанка, живучесть по фанке, где найдено). Дальше агент по протоколу
`docs/creatives/PROMPTING.md §0–§1`: разбор каждого крео → кластеризация подходов →
references/hooks в реестр → отчёт разведки (гейт R9).

## Tyver — правила фильтрации

> Главный принцип: **не сужай выдачу преждевременно** — кривые/жёсткие фильтры выбрасывают
> именно хорошие креативы. Лучше больше мусора в выдаче, но и больше живых находок.

### ❌ «Активность дней» — НЕ использовать
В Tyver даты стоят **некорректно**. Если поставишь «активность дней», большинство окейных,
рабочих креативов отфильтруется и ты их не увидишь. Фильтр не трогаем.

### ⚠️ «Дата создания» — плавающее значение, смотреть в ОБОИХ режимах
Это не жёсткий фильтр, а переключаемый срез — просматривать и так, и так:
- **С `30 дней`** — видишь свежие креативы.
- **Без даты / `Всё время`** — захватываешь креативы, которые льются **дольше 30 дней**
  (долгожители = проверенные временем винеры; именно их «30 дней» отрезает).
Не фиксируйся на одном срезе — пройти оба.

> ⚠️ **Даты Tyver НЕ показывают реальную открутку.** «Активность N дней» в Tyver
> некорректна (Tyver может показать 4–5 дней, но это не наша достоверная информация).
> Если набрал креативы, ориентируясь на даты Tyver, — **часть из них может уже вообще не
> литься** (неактуальны). Реальную длительность открутки узнавать **только по фанпейджу**
> (см. ниже), а не по датам Tyver.

### Тип поиска и ключевики
- Искать **напрямую по названию слота** и его вариациям: `chicken road`, отдельно
  `chicken road 2`. Смотреть и CR1, и CR2.
- Тип поиска — `точный` для названий; ослаблять, если выдача пустая.

### Поиск по Call to Action (без ключевиков)
Убрать ключевики, оставить **Geo + CTA**. CTA = кнопки, которые ставят на FB-объявление:
`Play Game`, `Download` («скачать и играть»). Срез по кнопкам вытаскивает креативы, которые
не находятся по тексту. Валидный самостоятельный заход.

### Вертикаль: Gambling — ДА, подкатегорию — НЕТ
Выбрать вертикаль `Gambling`, но **подкатегорию после Gambling НЕ выбирать** — она сильно
режет выдачу и показывает мусор. Оставлять верхний уровень.

### Гео — широко, не сужать до одной страны
- Страну ставить можно, но **не ограничивать жёстко до одной** (напр. только Ghana) — теряешь
  смысл. В широкой выдаче будет мусор (в т.ч. «голые женщины»), но глубже лежат кратно лучшие
  креативы.
- **Мультигео-креативы — брать**, если в Ad Library видно, что они **активны >2 недель**
  (живучесть = сигнал «работает»). Не отбрасывать только за то, что не строго под наше гео.

### Поле «в ссылке» — много ключевиков воронки
Не только `fbp=` / `pixel=`. Добавлять короткие маркеры воронки: `google.play`, просто `play`.
Чем больше ключевиков перебираешь — тем перспективнее и результативнее выдача. Ограничений нет.

### Прочие срезы
- **Фанпейдж** (по названию) и **доменная зона** — тоже валидные фильтры поиска.
- **Копать вглубь:** «прыгать по фанкам», ходить по прямым ссылкам объявлений, досматривать —
  поверхностная выдача у всех одна, глубина даёт уникальные находки.

## 🔑 Workflow «Tyver → Ad Library по фанпейджу»
Самый ценный приём — раскрутить найденную фанку до всей её истории:
1. В Tyver нашёл рабочий креатив популярной фанпейджи (напр. первые 5 крео по Chicken Road).
2. Перейти **на саму фанпейдж** (именно на страницу, **НЕ по ID фанпейджа**).
3. Открыть **Facebook Ad Library по этой фанке** — там видна **вся история её креативов**
   (что и сколько крутит, какие живут долго).
4. Оттуда — выкачать все её рабочие крео (статика + видео), добрать паттерны
   (скачивание из Ad Library — через браузерный плагин-загрузчик).

## Сколько реально проливается креатив — только по фанпейджу
Достоверно узнать, как долго крутится креатив (= рабочий он или уже выгорел), можно
**только глядя на фанку** (фанпейдж в FB Ad Library), не по датам Tyver. Долгая открутка
по фанке = сигнал «работает». Прямого счётчика «сколько крутится» нет — смотреть именно
на фанку конкурента.

Ориентир окна открутки: **3–5 дней** активности по фанке.

### Если фанка не открывается — обходим фильтры
У фанки могут стоять фильтры доступа. Диагностика по сложности:
- **Фильтр по гео** — простой: поставить **мобильные прокси нужного гео** и зайти/посмотреть.
  Лучший вариант — **открыть с телефона** (мобильный IP/устройство гео).
- **Фильтр по языку** — сложнее **в разы**. Не залипать: **лучше поискать другую фанку**, чем
  пробивать языковой фильтр.

В Ad Library метка **«Low impression count / <100»** = свежий, ещё не разогнанный тест конкурента
(сигнал нового рабочего захода).

## ⚠️ Глубина = меньше конкуренции (ключевой принцип)
**Чем быстрее и легче ты нашёл креатив — тем так же легко его найдёт другой вебмастер, и вы
его выжжете.** Таких вебмастеров огромное количество. Поэтому поверхностный быстрый поиск =
выгоревший креатив. Широкий гео + перебор ключевиков (CTA, «в ссылке», вариации названия) +
«прыжки по фанкам» вглубь дают креативы, которых нет на поверхности — они живут дольше и
конвертят лучше. Это стандартная рабочая практика, не лениться.

## Что дальше (находка → залив)
- Первые рабочие крео можно **сразу качать, заводить в кампанию и проливать** — смотреть, как
  отрабатывают (по статистике потоков). Параллельно копать ещё (до 10+).
- Выкачанное → реестр (`docs/creatives/geo/<GEO>/slots/<SLOT>.yaml`, `references` с
  `source: tyver` / `ad_library`) → отсев/доработка под нашу формулу → генерация челленджеров.
- Структура залива найденного — `pwa-tracker.md` (мульти-поток OS + сплит-тест PWA/офферов).
