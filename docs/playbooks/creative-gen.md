## 🟢 GAMBLING-FREEDOM (главное правило отдела)

заранее согласовано, разрешение получено, документы подписаны (под NDA). Это даёт право

→ В текстах и креативах **НЕ занимаемся самоцензурой:**
- **Никаких дисклеймеров/плашек** «играй ответственно» и т.п. — не нужны.
- **Жёсткие хуки разрешены** (деньги, выигрыш, вывод, бонус — прямо, без смягчения).
- **Полная свобода эксперимента** — углы, тон, агрессивность подбираем по эффективности, не по страху бана.
- Старый self-imposed guardrail «запретные слова» (`guaranteed/free money/hack/cheat`) — **снят** по решению байера.

> Граница: соглашение про **гемблинг-вертикаль**. Если когда-то всплывёт отдельная deception-policy
> Meta (вводящие в заблуждение обещания — это НЕ про гемблинг как таковой) — вернуться к байеру.
> По умолчанию: свобода, экспериментируем.

## Что брать из разведки: РАБОТАЮЩЕЕ, не «свободные слоты» (главный принцип)
Цель разведки — найти то, что у конкурентов **реально крутится и масштабируется** (проверено их
деньгами), и **копировать рабочие связки**. НЕ искать «незанятые ниши» / «чего никто не делает».

- **Сигнал «работает» = долго в ротации + много объявлений** (в Ad Library смотреть дату запуска и
  число копий). Долго и массово крутят → окупается, иначе бы остановили (это их бюджет).
- ⛔ **«Свободный слот» — это red flag, а не находка.** Если 20+ конкурентов чего-то НЕ делают —
  вероятнее всего они это тестировали и оно НЕ зашло, а не «ниша пустует». Дифференциация ради
  уникальности на холодную аудиторию = слив. Единственное исключение — есть прямое доказательство,
  что подход работал (свой винер с FTD или конкурент, который явно на нём скейлит).
- **Образец для копирования — лидеры ротации СВОЕГО типа.** Performance-affiliate (как мы) копируем
  по связке: формат / хук / сумма / эмоция / язык. Бренды (Betway, Betano, 1xBet…) механически НЕ
  копируем — они скейлят на узнаваемости и большом бюджете, у нас же прямой отклик.
- **Образец, язык, суммы, хуки, форматы — агент выбирает САМ из анализа** (кто и что скейлит).
  К байеру по этим пунктам не ходим. К байеру — только бюджет / стратегия / выбор из финальных
  вариантов / go перед заливом.
- Язык и суммы — **как у скейлеров рынка**, не изобретать. Весь рынок на English с крупными
  суммами → берём это, а не «уникальный» Pidgin со скромными цифрами (урок GH_AVI 2026-06).

## Воркфлоу
1. **Анализ (не сразу промт):** сверься с реестром — `market_profile` (язык/деньги/девайсы/лица), `production_profile` (стиль гео), `hooks` (что генерим). См. `market-profile/<GEO>.md`.
2. **Референс ОБЯЗАТЕЛЕН** (скрепка→файл): свой винер (напр. CR005) ИЛИ конкурент из `media/`. Генерация всегда reference-based, не text-to-image.
3. **Тип кадра** + его «правила правдоподобия»: пост в ленте / скрин чата / скрин игры / before-after / фото человека — у каждого своя нативная структура.
4. **Генерация 2-3 варианта** на креатив → менять ОДНУ переменную между вариантами.
5. **Критический отсмотр** (глазами байера: анатомия/текст/логика/реализм, не по галочкам промта). Брак = **REJECT**. СЕРИЮ смотреть в совокупности на единообразие.
6. **Телефон в кадре = Android** для Tier-3 (исследовать в `market_profile`, как и всё в кадре).
7. **Конкуренты:** искать СКЕЙЛЯЩИХСЯ (долго в ротации + много копий) → копировать их связки (см. принцип «РАБОТАЮЩЕЕ, не свободные слоты» выше). Всегда выкачивать и СМОТРЕТЬ картинки + ЧИТАТЬ тексты карточек; в отчёт — обязательны.
8. **Uniquify** отобранных — `uniquify_creatives` (3 копии/адсет, md5-разные) → `~/Documents/FB_Agent_Creo/`.
9. После работы — кликабельная `file://` ссылка на ПАПКУ (не пофайлово), проактивно.

## Промт-инжиниринг (свод; полное обоснование — было в PROMPTING.md)
**Структура промта** (блоками, от общего к частному): тип/формат кадра (`authentic Facebook post screenshot, NOT a glossy ad`) → субъект+сцена → камера/реализм (`shot on phone, natural light, candid`) → точный текст в кавычках с местом → инварианты/запреты в конце. GPT Image 2 — reasoning-first: ясное описание > «хаки».

**Анатомия** (частый брак): позитивные якоря `hands natural with five fingers, relaxed pose, correct proportions`; упрощай позу (одна рука в действии, вторая вне кадра); ломается — кадрируй вне кадра; мелкое лицо не детализируй. Негативы — умеренно (2-4 пункта, не длинный список).

**Текст на картинке** (наш частый факап): точные строки в кавычках + `render exactly`; указывай МЕСТО каждого текста (`inside the green button`, `caption above`); анти-«текст не туда» (`chat input must be EMPTY`); локальные слова (Pidgin/Twi) короткими + суммы дублировать цифрами; якорь `no gibberish, correctly spelled`.

**UGC, не глянец** (Tier-3 критично): описывай реальный момент, не фотосессию. `casual camera-roll photo, natural imperfections, off-center, NOT studio lighting`; бытовой фон (киоск MoMo, улица Accra); конкретная эмоция (`skeptical then relieved`); нативный UI платформы (FB-пост/WhatsApp). **НЕ пиши `ultra realistic / 8k / masterpiece`** — делает картинку искусственнее.

**Инварианты при перегенерации:** меняй одну вещь за раз, остальное фиксируй явно (`keep same layout/profile/colours; only fix the badge text`). Рестарт чата между батчами.

**Чеклист перед «ready»:** руки/поза анатомичны · весь текст осмысленный и в нужном месте · суммы/CTA корректны (валюта, бонус) · Tier-3 народно, девайс Android · похоже на реальный пост, не на AI-рекламу · нет чужих надписей/лого.

Источники: OpenAI GPT Image cookbook, learnprompting (deformed fixes), UGC-гайды.

## Грабли браузера (syntx headless)
Тормоза syntx-UI — это **НЕ слабый браузер** (одиночный Chromium быстр: UI ~2.5с), а **системный memory pressure** (RAM/swap). Рычаги:
- **Закрыть VS Code (~1.9 GB)** на время генерации — освобождает больше всего.
- playwright-MCP → лёгкий `chromium-headless-shell` (в `data/playwright-mcp.config.json`), не полный Chrome-for-Testing.
- Чистить раздутый кэш профиля (логины целы): `rm -rf data/recon_profile/Default/Cache "data/recon_profile/Default/Code Cache" data/recon_profile/{GraphiteDawnCache,ShaderCache,GrShaderCache}`.
- Проверка: `sysctl vm.swapusage` (used→0). `--disable-gpu` НЕ ставить (бесполезен/вреден для canvas-SPA). Правки конфига — после рестарта Claude Code.
