# Playbook: Видео-креативы (video)

> Источник правды агента `video`. Читать ПЕРЕД разведкой/генерацией. Правки — только с апрува байера.
> Полная техническая фактура (модели/цены, паттерны GH) — `docs/creatives/geo/GH/reports/AVI_video_research.md`;
> этот playbook = операционная выжимка «как делать».

## Статус
- ✅ **работает:** видео-разведка Ad Library (`recon_video.py` / `recon_video2.py` text-fallback без логина / `recon_adlib.py`), ffmpeg-раскадровка, образцы скачаны (`media_video/`); залив видео у `fb` — `MediaUploader.upload_video` (gRPC UploadVideo); **uniquify видео** — `scripts/uniquify_video.py` (новый md5 + невидимые микро-изменения: кроп 1-2px, тон, шум, ±0.5% скорости; раскладка `{1..N}/` как у картинок; тесты `tests/unit/test_video_uniquify.py`).
- ⚠️ **грабли:** mp4 агент НЕ «смотрит» напрямую — только раскадровка; скачивание mp4 headless иногда фейлится → постер+метаданные; модели ≤15с, рабочие паттерны 20–32с → склейка сегментов (ffmpeg concat); Meta активно режет gambling-видео у конкурентов → закладывать запас вариантов.

## 🟢 Gambling-freedom распространяется на видео
Соглашение с Meta (см. `creative-gen.md` §gambling-freedom) покрывает и видео: без самоцензуры,
жёсткие хуки разрешены, дисклеймеры не нужны. Подтверждение проходимости: в Ad Library МАССОВО
крутятся гемблинг-видео, прошедшие верификацию. Конкурентов без соглашения Meta режет
(«didn't follow Advertising Standards») — для нас их disabled-креативы = разведсигнал, не запрет.

## Доступ
- **Генерация:** syntx.ai → раздел «Видео», Playwright MCP на профиле `recon_profile` (как статика). Баланс ~2 595 кр (2026-06-04); **«ген» = сколько роликов с баланса** (больше ген = дешевле модель). Гемблинг через syntx проходит без блокировок.
- **Разведка:** `recon_adlib_profile` (headless), НЕ боевой Vision. Проект-на-оффер и «Новый чат» между батчами — как в `creative-gen.md`.

## Разведка (видео Ad Library)
- Запросы: `aviator` / `aviator <geo>` / `1xbet` / `betway` / `bang` / `spribe` / `crash game` / `mostbet` / `melbet`. **Фильтр: только видео.**
- **Сигнал «работает» = долго в ротации + много копий** (проверено их деньгами; однодневки = шум). Принцип «РАБОТАЮЩЕЕ, не свободные слоты» (`creative-gen.md`) применим полностью.
- Качать mp4 + постер → `docs/creatives/geo/<GEO>/reports/media_video/`. Фиксировать: Library ID, копии, дата старта, статус (active/**disabled** — тоже сигнал: работало → срезали), длина, назначение (Google Play app / web-PWA).
- В отчёт — раскадровки и выводы по паттернам, не просто список ссылок.

## Анализ (как «смотреть» видео)
1. `ffmpeg -i in.mp4 -vf fps=1 frames/frame_%02d.jpg` (раскадровка по секунде) ИЛИ первый/средний/последний кадр → смотреть кадры как картинки (Read).
2. Не вышло скачать/раскадровать headless → постер + метаданные карточки.
3. Чеклист разбора: **хук 0-3с** (крупная цифра/эмоция) · **звуконезависимость** (понятно без звука? в ленте звук выключен) · длина/темп · 9:16 · динамика (множитель/краш/реакция) · оверлеи и CTA-момент · что показывают (геймплей/лицо/MoMo-пруф/split) · назначение (app vs PWA).

## Паттерны (GH/Aviator, 2026-06; полные разборы — в отчёте)
1. **Геймплей-экран** (Bang — скейлит): баланс GHS 75K–318K, «FLEW AWAY»+множитель, история множителей, «TAX FREE»; звуконезависим, 20–32с, хук-цифра 0-3с. Воспроизводимо: **I2V Kling от статик-геймплея** (2 сегмента × 15с при нужной длине) или скринрекорд реального UI.
2. **Split-UGC duet** (Samuel — 13 копий/4 дня): 2 реальных человека, видеозвонок ~47с. **Нужны реальные люди** — AI-talking-head на 47с = риск артефактов; аватары только для коротких сегментов.
3. **Короткий бренд-CTA** (Betway 15с) — для не-брендов слабо, механически не копировать.

**Признаки рабочего видео:** правдоподобно-крупный баланс (не фейк-млн) · реальный геймплей-UI · момент краша/выигрыша · локальный типаж · хук-цифра первой · работает без звука.

## Воркфлоу
1. Вводные (оффер/гео/бонус) + `market-profile/<GEO>.md` + `offer-profiling.md`.
2. Разведка → отчёт паттернов (раскадровки конкурентов, Library ID, копии).
3. План серии: паттерн × модель (таблица) × N концептов; статик-вход — Gate-A винер от `syntx` (или запросить у него first/last кадры под Keyframes).
4. Генерация **2-3 варианта на концепт**, менять ОДНУ переменную; «Новый чат» между батчами.
5. **Самоотсмотр раскадровкой СВОИХ генератов** по QA-чеклисту видео (ниже) → брак REJECT.
6. → qa **Gate AV** (mp4 + раскадровки + промты/модель + статик-источник + референсы).
7. После ✅ — **uniquify аппрувнутых**: `python scripts/uniquify_video.py <mp4...> --offer <OFFER> --copies 3` (копии в `~/Documents/FB_Agent_Creo/.../{1,2,3}/`; `--no-speed` если длительность критична). Уникализируем ПОСЛЕ приёмки — qa смотрит оригиналы.
8. Папка `fb` на залив (`upload_video`); file://-ссылка на папку байеру.

## QA-чеклист видео (прогонять КАЖДЫЙ ролик; пополняемый — новый кейс → дописать сюда)
Применяет `video` при отборе и `qa` на Gate AV. Смотреть РАСКАДРОВКУ, не верить промту.
- **Хук 0-3с:** крупная цифра/эмоция уже в первых кадрах.
- **Звуконезависимость:** смысл считывается по кадрам без аудио (оверлеи/визуальный сюжет).
- **Формат:** 9:16; длина по паттерну (геймплей 15–32с).
- **Драматургия:** рост множителя → краш/кэшаут → реакция; ключевой момент не позже середины; без мёртвых пауз.
- **Суммы:** правдоподобны, валюта гео, **синхрон экран↔оверлей↔текст объявления** (одна цифра везде).
- **UI игры:** реальный и НАПОЛНЕННЫЙ (история множителей, кнопки, баланс) — чеклист статики (`creative-gen.md`) применим к каждому кадру.
- **Оверлеи/текст:** орфография, без gibberish, CTA-момент есть.
- **Люди в движении:** без морфинга рук/лиц между кадрами, липсинк не плывёт.
- **Брендинг:** без чужих лого И без вотермарок генераторов.
- **I2V-консистентность:** первый кадр = аппрувнутый статик; финальный кадр соответствует замыслу.
- **Серия целиком:** N разных сигналов, не один ролик ×N.

## Грабли
- mp4 напрямую не смотрится — ВСЕГДА раскадровка (и для своих генератов).
- Headless/RAM — те же рычаги, что в `creative-gen.md` (закрыть VS Code, headless-shell, чистка кэша профиля).
- Склейка сегментов: `ffmpeg -f concat` без перекодирования (одинаковые кодек/разрешение сегментов).
- Залив: видео-кампания у `fb` — `MediaUploader.upload_video` (chunked gRPC), thumbnail = постер-кадр.
