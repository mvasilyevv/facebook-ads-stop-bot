## 4. Инсайты по метрикам

- **KE / Chicken Road 2: M-Pesa = ключевой триггер доверия (2026-05-30).** Из ~600
  кликов по KE_CR2 в мае депозиты дал ровно один угол — `Payment Trust / M-Pesa`
  (KE_CR2_CR005: 2 FTD из 30 кликов). M-Pesa в тексте вообще поднимает кликабельность
  (3 разных M-Pesa-угла собрали клики), но конвертит именно формулировка про
  **гарантию выплаты на M-Pesa**, а не «withdrawal proof». Гипотеза: на KE сначала
  продаём «деньги реально приходят на твою M-Pesa», уже потом — игру/выигрыш.
- **Двойной URL-энкодинг макросов в ext_sub6.** Один угол приходит в трекер в 3-4
  вариантах (`M-Pesa angle`, `M-Pesa+angle`, `m-pesa+angle`) — при чтении статистики
  суммировать руками, не считать за разные углы.
- **ИСПОЛНЕНИЕ > угол (2026-05-30).** Один и тот же M-Pesa-отзыв в формате нативного
  FB-поста (CR005) дал 2 FTD, а в формате «фото телефона в руке» (CR003) — 0 рег при
  80 кликах. На KE решает не тема, а подача: нативный пост + выделенный пруф зачисления.
- **Direct-response баннеры не конвертят на KE (2026-05-30).** 4 «красивых» баннера
  с оффером 153 KES/100% bonus (CR001/002/004/006) собрали 224 клика и 0 рег. Клик
  ≠ намерение; нужен соц-пруф-формат, а не продающий баннер.
- **Целевые метрики воронки (ориентир, 2026-06-09).** Чтобы математика залива сходилась:
  **клик→инст (PWA) >40%**, **инст→рег 15–17%**, **клик→рег >10%**, **клик→деп >6%**. Если
  упираешься ниже — проблема в креативе/PWA/оффере, надо переразбирать связку, а не доливать.
- **Attribution gap Meta↔трекер — норма (2026-06-09).** FB-лиды/заверш.рег и трекер-рег/деп НЕ
  совпадают (на капе 09.06: FB 32 лида / 4 заверш. vs трекер 50 рег / 11 деп). Решения о
  прибыльности и FTD — **ВСЕГДА по трекеру AdSet.pro**; FB-метрики — только для CPC/CTR/деливери.
- **DRC / Casongo (RegPage MV) — лучшая связка кабинета (наблюдение, 2026-06-09).** На капе 09.06:
  658 кликов → 194 инст (29.48% клик→инст, топ) → 46 рег → 8 деп / $40. Тянет результат, в отличие
  от KE/GH — кандидат на масштаб параллельно GH-перезаливу. ⚠️ Снапшот капа, перепроверить по
  трекеру (`get_tracker_stats`) перед решением о бюджете.
- **Разведка креативов через Tyver — правила (2026-06-09).** НЕ ставить «Активность дней»
  (даты в Tyver кривые → режет хорошее); «Дата создания» смотреть И с 30 днями, И без («Всё
  время»); Gambling без подкатегории; гео широко, мультигео-крео брать если в Ad Library живут
  >2 недель; искать по CTA (Play Game / Download) + Geo и по полю «в ссылке»
  (`fbp`/`pixel`/`google.play`/`play`). **Workflow:** нашёл крео в Tyver → перешёл на саму
  фанпейдж (НЕ по ID) → открыл её в FB Ad Library → выкачал всю историю её креативов. Tyver —
  не единственный канал: параллельно MCP-агент-анализ. **Реальную открутку проверять по фанке**
  (даты Tyver некорректны → часть крео может уже не литься); фанка не открывается → гео-фильтр
  обходим мобильным прокси/телефоном, языковой фильтр — ищем другую фанку. ⚠️ Что легко нашёл ты —
  легко найдёт другой веб и вы это выжжете → копать глубже (вариации ключевиков, «прыжки по
  фанкам»). Цель — 10+ крео (CR1 и CR2, статика + видео). **Разделение труда (2026-06-09): сбор —
  байер вручную, агент — анализ собранного.** Полный гайд — `playbooks/spy-tyver.md`.
- **Структура залива: мульти-поток по OS + сплит PWA (2026-06-09).** В adset.pro разбивать
  кампанию на потоки Android/iOS/Other (каждый независим) и сплит-тестить 2 PWA (и при наличии
  2 оффера) внутри потока. Оффер — в КАЖДЫЙ поток. 2 PWA делать максимально разными. Заливать на
  2 кабинета для вариации аудитории. Детали — `playbooks/pwa-tracker.md`.
