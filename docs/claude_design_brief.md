# Claude Design — бриф для FB Stop Bot

> Промпты для claude.ai/design. Цель — улучшить дизайн веб-дашборда (`frontend/`) и
> Telegram Mini App (`frontend-mini/`) и привести их к единому языку.
> Создано: 2026-06-06.

---

## Как пользоваться

claude.ai/design (Anthropic Labs, research preview, нужен Pro/Max/Team/Enterprise).
Слева чат, справа канвас: описываешь — Claude рисует рабочий макет. Готовый дизайн
упаковывается в handoff bundle и передаётся в Claude Code на реализацию.

**3 шага под этот проект:**

1. **Онбординг → Design System.** Не начинай с пустого промпта. Скорми то, что уже есть:
   - `docs/frontend_design.md` — готовая спека дизайн-системы (v1.0).
   - `frontend/src/styles/` — токены (`tokens.css`, `globals.css`).
   - web-capture: сними живой UI дашборда, чтобы прототипы были «как настоящий продукт».
   - Включи toggle **Published** — иначе проекты возьмут дефолтную систему, а не твою.
2. **Главный бриф** (ниже) — первое сообщение в новом проекте.
3. **Итерации + handoff.** Чат — структурные правки, комментарии на канвасе — точечные.
   Когда нравится → handoff bundle → Claude Code реализует в `frontend/` и `frontend-mini/`.

**Ключевое решение брифа:** канон = editorial-monochrome веба (warm off-white `#F5F1E8`,
острые углы). Mini app подтягиваем к нему. Сейчас mini app в другом стиле — «Neo Control
Room», оранжевый `#FF6B00`, скругления 12px. Хочешь наоборот — поменяй раздел «ДИЗАЙН-ЯЗЫК».

## Главный бриф (вставить первым сообщением)

```
КОНТЕКСТ. FB Stop Bot — внутренний operator-tool для арбитража трафика: мониторит
Facebook Ads, шлёт алерты, отключает объявления, создаёт кампании. Два клиента,
один и тот же оператор: (1) веб-дашборд — desktop 1280px+, сидят в нём по 6–8 часов;
(2) Telegram Mini App — мобайл, тот же человек «на ходу».

АУДИТОРИЯ. 1–2 ad-ops профи. Цель — минимум когнитивной нагрузки, мгновенный доступ
к состоянию алертов, ноль визуального шума. Это не лендинг и не marketing site.

ДИЗАЙН-ЯЗЫК (канон). Editorial monochrome, тёмная тема. Единственный accent —
warm off-white #F5F1E8. Острые углы (radius 0 по умолчанию). Без drop-shadow:
объём — через border + сдвиг фона. Шрифты: JetBrains Mono (заголовки и все числа,
tabular-nums), Inter Tight (текст). Eyebrow-маркеры uppercase («01 / ОБЗОР»).
Плотность как Bloomberg Terminal, рендер как Linear/Vercel. UI на русском;
ad-ops жаргон латиницей: spend, CTR, CPM, CPL, CPA, ROAS, offer, draft, creative.
FSM-состояния русскими лейблами: Норма / Предупреждение / Стоп / В работе / Отключено.

ЗАДАЧА — 4 направления:

1) КОНСИСТЕНТНОСТЬ (приоритет). Сейчас веб и mini app выглядят как два разных
продукта: веб — editorial monochrome warm-white; mini app — «Neo Control Room»,
оранжевый #FF6B00, скругления 12px, glow-тени. Привести оба к ЕДИНОМУ языку (канон —
веб). Mini app адаптировать под мобайл/тач, но сохранить ту же палитру, типографику,
острые углы и eyebrow-маркеры. Telegram-специфику уважать (safe-area, нижний tab-bar,
theme params), НО брендовый accent — warm off-white, не оранжевый.

2) ВИЗУАЛ И ПОЛИРОВКА. Типографика как герой. Отступы строго по 4px-сетке. Единая
иерархия. KPI-карточки (большое число + тренд). Плотные таблицы с правым выравниванием
чисел. FSM-бейджи (pill + цветная точка). Никакого «soft UI», скруглений и мягких теней.

3) UX И НАВИГАЦИЯ. Снизить число кликов до действия. Понятные loading / empty / error
состояния (editorial-тон, напр. «Алертов за 24ч нет — значит правила работают»).
Per-screen:
   • Dashboard — «что происходит прямо сейчас» в один экран: KPI-полоса, spend×час,
     активные инциденты, лента событий, очереди задач.
   • Ads — рабочая лошадка (60% времени): фильтр-бар, виртуализованная таблица 1000+
     строк, bulk-выделение → нижний action-bar (Disable/Snooze), правый drawer с timeline.
   • Drafts — карточки одобрения AI-мутаций: что именно изменится (diff current→target),
     обоснование, таймер протухания, [Cancel]/[Approve & execute].
   • Offers — сетка карточек оффера + редактор правил (6 числовых порогов).
   • History — сводка слева / таймлайн справа, day-разделители, drill-down в drawer.
   • Settings — таб-навигация (Observer/Telegram/Vision/Workers/AI/Health), форма + статус.
   Mini app — три экрана, которых в вебе нет как отдельных (там это drawer или таб):
   • Ad Detail — то, что в вебе живёт в drawer: снапшот объявления, мини-график метрик,
     timeline алертов, история задач. На мобиле — полноэкранная страница.
   • Health — здоровье воркеров (в вебе это таб внутри Settings): список воркеров,
     heartbeat-статусы, общий вердикт HEALTHY / DEGRADED / CRITICAL.
   • Scripts — создание кампаний по скриптам: выбор папки с креативами, план запуска.

4) ДОСТУПНОСТЬ. WCAG 2.1 AA минимум (AAA по контрасту где можно). Видимый focus
(outline 2px accent). Полная клавиатурная навигация, Esc закрывает drawer/modal.
В mini app тач-цели ≥44px. Уважать prefers-reduced-motion.

ЭКРАНЫ. Веб (6): Dashboard, Ads, Offers, History, Settings, Drafts.
Mini app (9): Dashboard, Ads, Ad Detail, Drafts, Health, History, Offers, Scripts, Settings.
Различия осознанные: что на десктопе drawer/таб — на мобиле отдельная страница.

ЧТО ХОЧУ НА ВЫХОДЕ: (а) единый токен-набор (цвет/типографика/отступы/радиусы) для обоих
клиентов; (б) high-fidelity макеты ключевых экранов веба; (в) мобильная адаптация тех же
экранов под Telegram Mini App. Начни с Dashboard в обоих форматах рядом, чтобы я увидел,
что они — один продукт.
```

## Карта страниц (быстрый справочник)

| Страница | Веб (`frontend/`) | Mini app (`frontend-mini/`) | Назначение |
|---|---|---|---|
| Dashboard | ✓ | ✓ | «Что сейчас»: KPI, spend×час, инциденты, лента событий, очереди |
| Ads | ✓ | ✓ | Список объявлений, фильтры, bulk disable |
| Ad Detail | drawer | ✓ страница | Снапшот + timeline метрик/алертов/задач одного объявления |
| Offers | ✓ | ✓ | Карточки офферов + редактор правил (6 порогов) |
| History | ✓ | ✓ | Таймлайн событий за период, drill-down |
| Drafts | ✓ | ✓ | Одобрение AI-мутаций (diff, таймер, approve/cancel) |
| Settings | ✓ | ✓ | Конфиг (Observer/Telegram/Vision/Workers/AI/Health) |
| Health | таб в Settings | ✓ страница | Здоровье воркеров, общий вердикт |
| Scripts | — | ✓ | Создание кампаний по скриптам (папка креативов + план) |

Принцип: на десктопе деталь = drawer/таб; на узком мобайле та же деталь = отдельная страница.

## Промпты для итераций (по одному, после главного)

**Единые токены:**
```
Собери единый токен-набор для обоих клиентов: цвета (graphite-шкала + warm off-white
accent + muted semantic), типографика (JetBrains Mono / Inter Tight, 8 размеров),
отступы (4px-baseline), радиусы (0 по умолчанию). Отдай как CSS custom properties в
формате Tailwind 4 @theme — чтобы лёг в frontend/src/styles/tokens.css.
```

**Адаптация mini app:**
```
Возьми Dashboard и Ads и сделай мобильную версию под Telegram Mini App: ширина 480px,
нижний tab-bar, safe-area снизу, тач-цели ≥44px. Тот же accent, типографика и острые углы,
что в вебе. Покажи, как FSM-бейджи и плотная таблица деградируют в карточки на узком экране.
```

**Прогон по экранам (по одному за раз):**
```
Теперь экран [Drafts / Offers / History / Settings] в обоих форматах (desktop + mini app),
по канону системы. Особое внимание — [для Drafts: diff current→target и таймер протухания /
для Ads: bulk action-bar и drawer / для History: day-разделители].
```

**Полировка под editorial-тон:**
```
Пройди по всем empty / loading / error состояниям. Empty — только тонкая иконка + текст
в editorial-тоне (без иллюстраций). Loading — skeleton для таблиц, 2px accent progress-bar
на переходах. Error — внутри карточки: иконка danger, текст ошибки моноширинным, [Retry].
```

**Проверка доступности:**
```
Прогони финальные макеты по WCAG 2.1 AA: контрасты, видимый focus, тач-цели, порядок
табуляции. Покажи контраст-рейтинги для accent и semantic-цветов на тёмном фоне.
```
