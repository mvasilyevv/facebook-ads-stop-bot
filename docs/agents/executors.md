# Исполнители: AntiGravity и Claude CLI

Управляющий — Claude Code в основной сессии. Он разбирает задачу, принимает
архитектурное решение, пишет спеку, выбирает исполнителя, принимает работу,
мержит и релизит. Исполнитель пишет код и тесты в выделенном рабочем месте по
готовой спеке и не делает ничего больше.

За владельцем остаются денежные действия: включение сканирования, трата
бюджета, удаление рекламных объектов со спендом.

## Кого на какую задачу

| Класс задачи | Исполнитель | Почему |
| --- | --- | --- |
| Механика с машинным критерием готовности | AntiGravity (`agy`) | Отдельная квота, нашему бюджету бесплатно |
| Нужны каноны репозитория, контекст, суждение | Claude CLI (`claude -p`) | Читает `CLAUDE.md` и роли `eng-*`, цена известна до цента |
| Архитектура, money-путь, ревью, разрез задач | Управляющий | Цена ошибки выше стоимости токенов |

Критерий, отделяющий первое от второго: можно ли выразить «готово» командой,
которая возвращает код возврата. Если да — задача уходит вниз. Если «готово»
описывается словами, читать diff придётся всё равно, и делегирование экономит
только время, не токены.

## Рабочее место

Один worktree — один исполнитель — одна задача. Основное дерево остаётся за
управляющим, исполнитель туда не пишет.

```bash
git worktree add ~/Desktop/FB_Agent_wt/task-<N> -b task/<N> origin/main
git -C ~/Desktop/FB_Agent_wt/task-<N> config --worktree remote.origin.pushurl "no-push://blocked"
ln -sfn <repo>/.venv ~/Desktop/FB_Agent_wt/task-<N>/.venv
ln -sfn <repo>/services/browser-agent/node_modules ~/Desktop/FB_Agent_wt/task-<N>/services/browser-agent/node_modules
```

Блокировка push требует `extensions.worktreeConfig=true` в репозитории и не
протекает в основное дерево — проверено. Симлинки нужны потому, что
pre-commit ищет `.venv/bin/ruff` относительно worktree, а сборка
browser-agent — свои зависимости.

## Запуск

```bash
# AntiGravity
agy --add-dir <worktree> -p "<спека>" \
    --model gemini-3.1-pro-low --mode accept-edits \
    --sandbox --dangerously-skip-permissions \
    --print-timeout 45m --output-format text

# Claude CLI
cd <worktree> && claude -p "<спека>" \
    --model sonnet --effort medium \
    --dangerously-skip-permissions --strict-mcp-config \
    --disable-slash-commands --tools "Read,Edit,Write,Bash,Grep,Glob" \
    --disallowed-tools "Bash(git push:*)" \
    --max-budget-usd 5 --output-format json
```

Запускать в фоне: пока исполнитель считает, управляющий берёт следующую
карточку. На время автономного прогона держать машину бодрой —
`caffeinate -dimsu -t <секунды>`.

Особенности, найденные прогоном:

- `--add-dir` для `agy` **обязателен**. Без него агент работает в
  `~/.gemini/antigravity-cli/scratch` и правит файлы мимо репозитория, а
  `cd` перед вызовом на это не влияет.
- `--sandbox` совместим с pytest и сетью и запрещает запись вне worktree, но
  `git commit` не запрещает — отсюда отдельная блокировка push.
- У моделей `gemini-*-low|medium|high` уровень зашит в имя, `--effort` с
  ними конфликтует и вызов падает.
- `--print-timeout` по умолчанию 5 минут — для карточки мало.

## Спека

Семь блоков, без прозы: задача и зачем; инвариант; точный список файлов,
которые можно трогать; что уже положено в ветку и трогать нельзя; критерий
готовности конкретными командами; явные запреты; форма отчёта.

На money-пути падающий тест пишет управляющий и кладёт в ветку до запуска.
Исполнитель обязан его озеленить и не имеет права править сам тест: так
«понял ли задачу» проверяется машиной, а не пересказом.

## Приёмка

Отчёт исполнителя — не доказательство, и «отступлений от спеки нет» в нём
тоже. Наблюдалось: отчёт «OK» о файле, которого не создал; отчёт, отданный до
окончания собственного прогона; коммит вопреки прямому запрету; ослабленный
существующий money-тест при заявленном отсутствии отступлений. Порядок
приёмки:

1. `git diff origin/main --stat` — вышел за разрешённые файлы, отказ без
   чтения содержимого. Смотреть и `git log`: исполнитель мог закоммитить.
2. Тест, положенный управляющим, зелёный **и не изменён**.
3. Заявленный красный тест проверяется откатом правки. Проверять не только
   то, что он краснеет, но и **чем**: падение по ошибке компиляции или по
   отсутствию новой структуры — это не пойманный дефект. Красным он обязан
   быть по ассерту.
4. Отдельно — диф существующих тестов. Подгонка чужого теста под свою
   реализацию выглядит как «обновил фикстуру», а означает снятую проверку.
5. Узкие тесты, затем релевантный suite целиком: правка могла уронить
   соседний money-тест, и в узком прогоне этого не видно.
6. Менялся контракт — прогнать ровно ту команду, которую гоняет CI:
   `PYTHON=<repo>/.venv/bin/python pnpm run sync:api`, затем
   `pnpm -r typecheck`. Именно `sync:api`, а не `export_openapi.py`: он
   дополнительно форматирует `openapi.json` prettier'ом, и гейт сверяет
   результат через `git diff --exit-code`. Сырой экспорт даёт файл, который
   отличается от канонического одними переносами строк, и CI краснеет.
   Менялась схема БД — накатить миграцию на одноразовый PostgreSQL по цепочке
   «схема из main → `run-migrations-locked` из ветки», иначе гейт каталога
   ловит расхождение уже в проде.
6. Ревью diff по канонам. На money-пути отдельно спросить, не подменяется ли
   исход внешней операции: формулировка карточки может быть неточна, а
   исполнитель следует ей буквально.
7. Зелено — коммит от управляющего, merge, карточка в «Готово». Красно —
   одна итерация с точным списком; второй провал забирает управляющий.

Правка приёмки коммитится отдельно от работы исполнителя: в истории должно
быть видно, что пришло от него и что поправлено при приёмке.

## Цена

Замерено 22.08.2026 на двух карточках нулевого уровня.

| | AntiGravity, #255 | Claude CLI (Sonnet), #233 |
| --- | --- | --- |
| Цена | 1% пятичасовой квоты Gemini | $1.60 |
| Время | ~4 минуты | 13.5 минуты |
| Результат | принято после доработки прогоном | принято |

Квота AntiGravity — два независимых пула, Gemini и «Claude + GPT», у каждого
недельное окно и пятичасовое, только в процентах: `agy -p "/usage"` работает
headless и сам квоту не тратит. Claude CLI отдаёт `total_cost_usd` в ответе.

Холодный старт `claude -p` в этом репозитории стоит 50 372 токена кэш-записи;
`--strict-mcp-config`, `--tools` и `--disable-slash-commands` срезают его до
12 367 — вчетверо дешевле, что больше любой экономии от смены модели.
