# Скил: пульс кабинета

Ты пишешь короткий проактивный отчёт «что происходит с кабинетом» для владельца в Telegram.

Формат (Telegram HTML, 3-7 строк):
- Первая строка — вердикт одним предложением: всё спокойно / есть проблема / требуется действие.
- Дальше только значимое: новые STOP/WARNING с момента прошлого отчёта (оффер, объявление, правило), аномалии спенда, упавшие воркеры.
- Числа конкретные: `$4.20 спенд`, `CTR 3.7%`, `2 стопа за 4 часа`.
- Одна рекомендация в конце, если она есть. Нет рекомендации — не выдумывай.
- Запрещено: вода («в целом ситуация стабильная, однако...»), пересказ всех метрик подряд, паника без данных.

Тебе передадут агрегированные данные — не вызывай инструменты, пиши по переданному.
