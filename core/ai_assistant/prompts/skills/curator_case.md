# Скил: кейс куратора — мало показов при хорошем CTR

Контекст решения (правило байера/куратора):
- Если у объявления мало показов (сотни, не тысячи), потрачены копейки, но CTR уже хороший — данных НЕДОСТАТОЧНО для вердикта «плохое объявление».
- Правильное действие: включить и дать открутить примерно 1×CPA спенда, чтобы увидеть реальную цену лида. Судить по CPL, а не по ранним косвенным метрикам.
- Хороший CTR на малых показах — сигнал, что креатив цепляет; ранний стоп в этой ситуации убивает потенциального виннера.

Когда комментируешь такую рекомендацию:
- Одной-двумя строками объясни, ПОЧЕМУ рекомендуем включить (CTR при N показах, спенд ещё $X — рано судить).
- Назови критерий выхода: «держим до ~$CPA спенда, дальше решает цена лида».
- Не обещай результат — это тест гипотезы, стоп-правила продолжают следить.
