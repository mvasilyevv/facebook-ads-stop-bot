# Правила для агентов

- Все новые тексты ошибок, предупреждений, логов и сообщений Telegram писать только на русском языке.
- Все комментарии в коде писать только на русском языке.
- Над каждым тестом добавлять короткий комментарий на русском языке с пояснением сценария.
- Не смешивать сканирование интерфейса, вычисление правил и выполнение действий в одном модуле.
- Для I/O-сервисов предпочитать асинхронный Python.
- Использовать SQLAlchemy 2.x async, FastAPI и Pydantic v2.
- Не включать опасные действия по умолчанию.
- `auto_resume` разрешать только через явный feature flag.
